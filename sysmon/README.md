# SysMon

タスクマネージャーよりコンパクトに、より多くの値をグラフ付きで一覧できるシステムモニター（Windows / .NET 10 WinForms）。

## 起動

- `run.bat` … 通常起動（初回は自動でビルド → `dist\SysMon.exe`）
- `run-admin.bat` … 管理者として起動（CPU 温度などを表示する場合）
- `build.bat` … `dist\SysMon.exe`（単一ファイル、.NET 10 デスクトップランタイム使用）を作り直す

アプリ内の「管理者で再起動」ボタンでも昇格できます。

## 表示項目

| タイル | 内容 |
|---|---|
| CPU | 使用率（**全スレッド / 平均** 切替。平均時はカーネル時間も重ねて表示）、周波数、温度・CCD 温度・SoC 温度、パッケージ電力、コア電圧、最大コアクロック、FCLK/UCLK/MCLK、プロセス・スレッド・ハンドル数、コンテキスト切替/s、割り込み/s、システムコール/s、実行待ちキュー、稼働時間 |
| メモリ | 使用率グラフ、構成（使用中/変更済み/スタンバイ/空き）、コミット、キャッシュ済み、ページ/非ページプール、ページフォールト/s、ハードフォールト/s、**読み書き帯域（実測, GB/s）**と理論ピーク比、DIMM 温度 |
| GPU | 使用率、VRAM 使用量、**VRAM 帯域（推定）**、エンジン別（3D/Copy/Decode/Encode）、温度・ホットスポット・メモリ温度、電力/上限、コア/メモリクロック、ファン（%・rpm）、PCIe 世代/幅・送受信量、P ステート、クロック制限理由、共有メモリ |
| ディスク（物理ドライブごと） | アクティブ時間、読み取り/書き込み速度、応答時間、IOPS、キュー長、温度、寿命残り、ボリューム使用量 |
| ネットワーク | 送受信速度（B/s と bps）、リンク速度、IPv4、起動後の累計、その他アダプターの送受信 |
| プロセス | 上位 12 件（同名はまとめる）。CPU / GPU / メモリ / I/O の列見出しクリックで並べ替え |
| センサー | マザーボードの温度・ファン回転数・電圧 |

グラフにマウスを乗せると、その時点の値がツールチップで出ます。上部バーで更新間隔（0.5/1/2 秒）・履歴長（60/120/300 秒）・最前面表示を切り替えられます。設定とウィンドウ位置は `%APPDATA%\SysMon\settings.json` に保存されます。

## 管理者権限と PawnIO について

CPU 温度・電力・電圧、マザーボードのファン/電圧、DIMM 温度、メモリ帯域はカーネルドライバ経由でしか読めません。
LibreHardwareMonitor（同梱ライブラリ）が使う **PawnIO** ドライバを入れ、管理者として起動すると表示されます。

```
winget install namazso.PawnIO
```

管理者でなくても、CPU/メモリ/ディスク/ネット/GPU の使用率・GPU 温度・ホットスポット・NVMe 温度などは表示されます。

## 値の出どころと注意

- **CPU 使用率**: `% Processor Utility`（タスクマネージャーと同じ。周波数を加味した値で、100% で頭打ち）
- **メモリ帯域**: Ryzen（Zen 2 / Zen 3 / Cezanne）の SMU PM テーブルにある UMC 読み書きカウンタ（`CS_UMC_READS/WRITES`）。Intel CPU では表示されません
- **VRAM 帯域（推定）**: NVML の「メモリコントローラ使用率」×現在のメモリクロックでの理論帯域。実測値ではなく目安です
- **ディスク温度**: `IOCTL_STORAGE_QUERY_PROPERTY` で取得（管理者不要）。古い SATA HDD などは非対応
- **プロセスの I/O**: ディスク以外（ネットワーク・デバイス I/O）も含む全 I/O 転送量

## 診断

`SysMon.exe --dump <ファイル>` で、取得できている値と LibreHardwareMonitor のセンサー一覧をテキストに書き出します。

画面確認用のスクリプト（開発用）: `tools\capture.ps1`（ウィンドウを PNG に保存）、`tools\click.ps1`（指定座標をクリック）、`tools\make-icon.ps1`（app.ico 生成）。
